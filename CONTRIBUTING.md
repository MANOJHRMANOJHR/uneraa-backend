# Contributing to Unerra Backend

Thank you for your interest in contributing! We welcome pull requests, bug reports, and feature suggestions.

## How to Contribute

1. **Fork the repository** and create your branch from `main` or the latest development branch.
2. **Install dependencies**: `npm install`
3. **Create a new branch** for your feature or bugfix: `git checkout -b feature/your-feature`
4. **Write clear, concise code** and include tests where possible.
5. **Run tests** before submitting: `npm test`
6. **Lint your code**: `npm run lint`
7. **Open a pull request** with a clear description of your changes.

## Code Style
- Use TypeScript and follow the existing code style.
- Run `npm run lint` and fix any issues before submitting.
- Keep functions and files small and focused.

## Reporting Issues
- Use GitHub Issues for bugs, enhancements, or questions.
- Provide as much detail as possible (steps to reproduce, logs, screenshots).

## Community
- Be respectful and inclusive.
- See our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping make Unerra Backend better!
