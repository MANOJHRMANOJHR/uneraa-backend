# 🚀 chetas-be

> ⚡ High-performance backend using [Bun](https://bun.sh), TypeScript, Express, and modern dev tools (Husky, ESLint, Prettier)

---

## 📦 Tech Stack

- **Runtime:** Bun v1.2.8
- **Language:** TypeScript
- **Framework:** Express
- **Formatting:** Prettier
- **Linting:** ESLint
- **Hooks:** Husky + lint-staged
- **DB:** MongoDB (with Mongoose)
- **Other:** Redis, JWT, Nodemailer, Socket.io, Swagger

---

## 🛠️ Getting Started

### 1️⃣ Clone and Install

```bash
git clone https://github.com/utkarshya24/chetas-be.git
cd chetas-be
bun install

```

## ✅ Hooks are automatically set up via postinstall script

### 2️⃣ Run the Server (Dev)

```bash
bun run dev
```
