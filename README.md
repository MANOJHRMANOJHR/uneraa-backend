# 🚀 UNERRA-BE

> ⚡ High-performance backend using [npm](https://npm.sh), TypeScript, Express, and modern dev tools (Husky, ESLint, Prettier)

---

## 📦 Tech Stack

- **Runtime:** npm v1.2.8
- **Language:** TypeScript
- **Framework:** Express
- **Formatting:** Prettier
- **Linting:** ESLint
- **Hooks:** Husky + lint-staged
- **DB:** Postgres (PRISMA)
- **Other:** Redis, JWT, Nodemailer, Socket.io, Swagger

---

## 🛠️ Getting Started

### 1️⃣ Clone and Install

```bash
git clone https://github.com/utkarshya24/unerra-be.git
cd unerra-be
npm install

```

## ✅ Hooks are automatically set up via postinstall script

### 2️⃣ Run the Server (Dev)

```bash
npm run dev
```
